有効な米国住所形式とは：標準、検証、よくあるエラー

📅 2026年8月更新🏷️ 住所形式ガイド⏱️ 約6分

米国のウェブサイトでフォームに記入したり、アカウントを登録したり、越境ショッピングをする際に、「無効な住所」や「有効な住所を入力してください」というエラーメッセージに頻繁に遭遇することがあります。問題は多くの場合、住所が存在しないことではなく、形式が米国郵便公社（USPS）の基準に準拠していないことです。この記事では、有効な米国住所のコア要素、検証ルール、よくあるエラーを体系的に説明し、住所の拒否を回避するのに役立ちます。

有効な米国住所のコア要素

USPSの公式仕様によると、標準的な米国住所には以下の必須要素が含まれます：

  • 受取人氏名：受取人のフルネーム。通常は姓名を含みます。
  • 番地：番地、通り名、通りタイプの接尾辞（例：St, Ave, Dr, Blvd）を含みます。
  • アパート/ユニット/スイート番号：住所にアパートやスイートが含まれる場合は、「#」「Apt」「Unit」「Ste」を使用して番地の後に記載する必要があります。
  • 市区町村：完全な市区町村名。ZIPコードおよび州略称と一致する必要があります。
  • 州略称：CA、NY、TXなどのUSPS標準の2文字大文字略称を使用します。完全な州名は使用しないでください。
  • ZIPコード：5+4桁形式が推奨されます（例：90210-1234）。基本の5桁ZIPコードも許容されます。

📌 標準米国住所例：

John Smith
123 Main St Apt 4B
Los Angeles, CA 90001-1234

USPS住所検証ルール

USPSはCASS（Coding Accuracy Support System）認証として知られる厳格な住所検証システムを運用しています。APIまたは一括で住所を提出する際、システムは以下のチェックを実行します：

  • 通り名の標準化：「Street」を「St」に、「Avenue」を「Ave」に標準化します。
  • 市区町村-州-ZIPのトリプルマッチ：市区町村名、州略称、ZIPコードが同じ地理的エリアを指していることを検証します。
  • 番地範囲検証：その番地が実際にその通りに存在するかを確認します。
  • 二次ユニット識別：二次住所識別子（Apt, Unit, Ste）が正しくフォーマットされているかをチェックします。
USPSは毎日4億2500万通以上の郵便物を処理しており、その約3％が住所形式エラーによる配送遅延や返送の影響を受けています。標準化された住所形式を使用することで、配送成功率が大幅に向上します。

住所拒否の一般的な理由

  1. 略称ではなく完全な州名を使用：多くの米国外のユーザーは習慣的に「California」と書きますが、「CA」と書くべきです。システムは2文字の略称を要求します。
  2. ZIPコードが市区町村と一致しない：各ZIPコードは特定の市区町村範囲に対応しています。市区町村名と一致しないZIPコードを選択すると、検証が失敗します。
  3. 通りタイプ接尾辞の欠落または誤り：一部のシステムは通りタイプの略称を厳密に検証します。「Maple Drive」の代わりに「Maple Dr」と書く必要がある場合があります。
  4. アパート/ユニット番号の欠落：複数ユニットの建物では、ユニット番号が欠落していると不完全な住所として扱われます。
  5. 特殊文字の問題：住所にピリオドとカンマ以外の特殊文字を使用すると、解析エラーが発生する可能性があります。

住所の有効性を確認する方法

  • USPS公式検証ツール：USPSウェブサイトのZIP Code LookupとAddress Validationページにアクセスして、個別の住所を無料で検証します。
  • サードパーティ住所検証API：SmartyStreets、Lob、EasyPostなどのサービスが一括検証と自動修正機能を提供しています。
  • アドレスジェネレーターを使用して準拠形式を取得：プロフェッショナルなアドレスジェネレーターは、USPS基準に準拠した住所を即座に生成し、100％の形式正確性を保証します。

  • ✅ ZIPコード形式が標準化（5桁または5+4）
