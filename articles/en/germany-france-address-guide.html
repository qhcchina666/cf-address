Germany & France Address Format Guide: European Address Writing Tips

📅 Updated August 2026 🏷️ European Address Format ⏱️ ~7 min read

For users accustomed to the US address format, filling out German or French addresses can be confusing. European address writing order, postal code placement, and format rules differ significantly from those in the United States. Incorrectly applying the US format to European addresses is the number one cause of form validation failure. This article provides a detailed guide to German and French address format standards, helping you accurately complete European addresses.

German Address Format Rules

German addresses follow a small-to-large hierarchical structure. A key difference from US addresses is that the postal code precedes the city name. The standard format is as follows:

  • Line 1: Recipient name (Vorname Nachname)
  • Line 2: Street name + house number (Straße Hausnummer), note that the house number follows the street name
  • Line 3: Postal code (5 digits) + city name (Postleitzahl Stadt)
  • Line 4: Country name (usually "Germany" or "Deutschland"); can be omitted for domestic mail

📌 German Address Example:

Max Mustermann
Hauptstraße 42
10115 Berlin
Germany

German Postal Code System

German postal codes (Postleitzahl, abbreviated PLZ) consist of 5 digits, uniformly implemented in 1993. The first two digits represent the region, and the last three represent the specific delivery area:

  • 0xxxx: Eastern region (Dresden, Leipzig, etc.)
  • 1xxxx: Berlin and surrounding areas
  • 2xxxx: Hamburg and northern region
  • 4xxxx: Düsseldorf and western region
  • 6xxxx: Frankfurt and central region
  • 8xxxx: Munich and southern region

German Address Special Character Handling

German addresses frequently contain special characters. Correct writing is important:

  • ä, ö, ü: Should be entered as-is. If the system does not support them, replace with ae, oe, ue respectively.
  • ß: Can be replaced with ss. For example, "Straße" can be written as "Strasse".
  • ß in street names: In modern German addresses, ß is common in street names, such as "Goethestraße".
When filling out English-language forms that do not support diacritical marks, using alternative spellings (ae/oe/ue/ss) is completely acceptable. The German postal system can correctly recognize these alternatives.

French Address Format Rules

French address format is similar to German, also following a small-to-large hierarchical structure, but with several important differences:

  • Line 1: Recipient name (Prénom Nom), typically with the surname in all caps
  • Line 2: House number + street name (Numéro Rue), house number comes first
  • Line 3: Postal code (5 digits) + city name (Code postal Ville), city name typically in all caps
  • Line 4: Country name (France); can be omitted for domestic mail

📌 French Address Example:

Jean DUPONT
15 Rue de la Paix
75008 PARIS
France

French Postal Code System

French postal codes (Code postal) also consist of 5 digits, with the first two digits representing the département:

  • 75xxx: Paris
  • 69xxx: Lyon and Rhône department
  • 13xxx: Marseille and surrounding areas
  • 31xxx: Toulouse
  • 06xxx: Nice

Notably, in Paris, the last two digits of the postal code represent the arrondissement: 75001 for the 1st arrondissement, 75008 for the 8th, and so on.

Practical Tips for Filling Out European Addresses

Master these tips to significantly reduce errors when filling out European addresses:

  • Remember the postal code position: In European addresses, the postal code comes before the city name — this is the most visible difference from US addresses.
  • Note the house number position: German addresses place the house number after the street name (Hauptstraße 42), while French addresses place it before (15 Rue de la Paix).
  • Handle special characters properly: On English-language forms, replace German umlauts with alternative spellings; French accent marks can be retained or removed.
  • Use an address generator: If you need to generate European addresses in bulk for testing, a professional address generator ensures 100% format correctness.
European postal systems are relatively tolerant of minor address format deviations — as long as the postal code is correct, mail can usually still be delivered. However, in form validation scenarios, strict format checks often require full compliance with standards.
