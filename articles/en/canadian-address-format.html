Canadian Address Format Guide: Province Codes, Postal Code Rules & Tips

📅 August 2026 · 🏷️ Canadian Address · Postal Code · Province Codes · Bilingual Addresses

As the world's second-largest country by land area, Canada's address system blends British and American traditions with French linguistic influences. Whether you are applying for immigration, registering for university, or engaged in cross-border e-commerce, understanding and correctly writing Canadian addresses is an essential skill. This guide covers everything you need to know about Canadian address format standards.

1. Standard Canadian Address Format

Canadian address structure closely resembles US addresses and also follows a three-line format, but there are notable differences in province codes and postal code format. Here is the standard structure:

Line 1: Recipient Name

As with most countries, the first line contains the recipient's full name. For business addresses, use the company name instead.

Line 2: Street Address

The Canadian street address format is: house number + street name + street type. If there is an apartment or unit number, it is typically placed before the street address, connected with a hyphen. For example:

4-123 Main Street
(Apartment 4, 123 Main Street)

Common Canadian street type suffixes are similar to those in the US, including Street (St), Avenue (Ave), Road (Rd), Drive (Dr), and Boulevard (Blvd). In Quebec, French street types are also common, such as Rue (Street), Chemin (Road), and Boulevard (Boulevard).

Line 3: City, Province Abbreviation, Postal Code

The Canadian third line follows the format: City, Province_Abbreviation  Postal_Code. Note that Canada Post recommends two spaces between the province abbreviation and the postal code, and a comma between the city and province abbreviation. For example:

Toronto, ON  M5V 2T6
Vancouver, BC  V6B 1A1
💡 Tip: Canadian province abbreviations use two uppercase letters, similar to US state abbreviations, but the set of provinces is entirely different. Do not confuse the two countries' abbreviation codes.

3. Canadian Postal Code: A1A 1A1 Structure Explained

Canada's postal code system is one of the most unique in the world, using an alternating letter-digit-letter digit-letter-digit format (ANA NAN). This design creates an enormous coding space, allowing each postal code to pinpoint a city block or even a single building.

Postal Code Structure

Using M5V 2T6 (a downtown Toronto address) as an example:

  • M (1st character) — Forward Sortation Area (FSA) first letter. M represents downtown Toronto.
  • 5 (2nd character) — FSA subdivision. 5 indicates an urban delivery area.
  • V (3rd character) — Further FSA subdivision, representing a specific post office or delivery zone.
  • Space — Separator between the FSA and LDU.
  • 2T (4th–5th characters) — Local Delivery Unit (LDU), representing a specific delivery route.
  • 6 (6th character) — LDU subdivision, representing a specific delivery segment or building.
💡 Key Rule: In Canadian postal codes, the letters W and Z have special meanings when appearing in the first position, but the letters D, F, I, O, Q, and U are never used in any position to avoid confusion with digits.

5. Practical Tips for Filling Out Canadian Addresses

  1. Postal Code Format Must Be Correct — Canadian postal codes must follow the ANA NAN format, with letters and digits alternating and a space in the middle. Do not use hyphens, and do not write it as a continuous 6-character string.
  2. Use Two-Letter Province Abbreviations — Never use the full name (e.g., "Ontario") or an old abbreviation (e.g., "Ont."). Always use the standard two-letter code "ON".
  3. Comma Between City and Province — This is consistent with the US format, but two spaces are recommended between the province abbreviation and the postal code.
  4. Apartment Number Before the Street Address — In Canadian convention, the apartment number is connected with a hyphen before the house number, e.g., "3-456 Maple St", rather than the US-style "456 Maple St, Apt 3".
  5. Pay Attention to Quebec Bilingual Addresses — When mailing to Quebec, it is advisable to provide both English and French versions, or at least ensure the address format complies with Canada Post standards.
